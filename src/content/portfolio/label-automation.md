## 무엇을 하는 프로그램인가

친절정육점은 BIXOLON Label Artist-II로 상품 라벨(.lafx)을 만들어 인쇄합니다. 라벨에는 이력번호, 가공일, 소비기한이 찍히고, 들어오는 고기가 바뀌면 이 값들도 함께 바뀌어야 합니다.

이 프로그램은 매장의 이력번호 관리대장(.xlsx)과 라벨 파일을 서로 맞춰 봅니다. 각 이력번호가 실제로 등록된 번호인지는 공식 축산물이력 조회로 확인합니다. 수입육은 MeatWatch, 국내산과 묶음번호는 축산물이력제(Mtrace)를 씁니다. 확인이 끝나면 라벨을 자동으로 백업한 뒤 같은 파일의 이력번호, 가공일, 소비기한만 새 값으로 바꿉니다.

라벨의 디자인이나 다른 문구는 건드리지 않습니다. 직원이 쓰던 폴더와 파일 이름도 바뀌지 않으므로, 작업이 끝나면 Label Artist-II에서 평소처럼 열어 인쇄하면 됩니다.

## 누구를 위한 것인가

매일 라벨을 고치고 인쇄하는 정육점 직원, 그리고 표시 정보가 정확한지 책임지는 매장 운영자를 위한 프로그램입니다. 화면의 메뉴와 안내는 모두 한국어입니다. 처음에 라벨 폴더와 관리대장 위치만 정해 두면, 그다음부터는 버튼 하나로 작업이 시작됩니다.

## 작업 흐름

1. 설정에서 매장이 쓰는 라벨 폴더와 이력번호 관리대장을 한 번 지정하고, 이력 조회 연결을 확인합니다.
2. 이번에 건드리지 않을 라벨이 있으면 예외 파일로 빼 둡니다.
3. '전체 라벨 수정'에서 '라벨 검증 및 수정'을 누릅니다. 라벨 하나만 고칠 때는 '개별 라벨 수정'을 씁니다.
4. 프로그램이 관리대장과 라벨을 대조하고, 공식 이력 조회로 번호를 확인한 뒤 백업을 만들고 라벨을 고칩니다.
5. 결과 화면에서 수정된 라벨, 제외된 라벨, 교체 시점이 된 이력번호를 확인합니다.
6. Label Artist-II에서 라벨을 열어 확인하고 인쇄합니다.

## 안전 설계

라벨에 찍히는 이력번호와 소비기한은 손님에게 그대로 보이는 정보입니다. 그래서 이 프로그램은 확실할 때만 고치고, 애매하면 멈추도록 만들었습니다.

- **고치기 전에 먼저 백업합니다.** 라벨을 바꾸기 전에 파일과 이력 기록을 자동으로 보관합니다. 백업 폴더를 따로 정할 필요는 없습니다.
- **언제든 되돌릴 수 있습니다.** 설정에서 백업 시점을 골라 전체 라벨이나 라벨 하나만 복원할 수 있습니다. 복원하기 직전의 상태도 다시 백업해 둡니다.
- **확실하지 않으면 멈춥니다.** 어떤 번호가 최신인지 정할 수 없을 때, 이력 조회 결과를 믿을 수 없을 때, 작업 도중 파일이 바뀌었을 때는 짐작으로 고치지 않고 작업을 멈춘 뒤 이유를 알려 줍니다. 상품 후보가 여러 개라면 직원에게 먼저 고르게 합니다.
- **파일을 망가뜨리지 않는 방식으로 바꿉니다.** 원래 파일을 먼저 지우거나 비우지 않고, 새 파일을 다 준비한 다음에 바꿔 넣습니다. 중간에 컴퓨터가 꺼지더라도 다시 켤 때 알려진 상태로 맞춰 놓습니다.
- **실패한 라벨을 성공으로 표시하지 않습니다.** 수정하지 못했거나 제외된 라벨은 결과 화면에 따로 보여 줍니다. 그래서 확인되지 않은 라벨이 확인된 것처럼 인쇄되는 일을 막습니다.

## 화면 디자인

화면 디자인의 이름은 'Cold Counter'입니다. 정육점의 스테인리스 진열대와 실제로 손에 쥐는 라벨에서 색을 가져왔습니다.

- 바탕은 냉장실 조명 같은 차가운 회색입니다.
- 작업 영역은 흰 라벨지처럼 보이도록 했습니다.
- 글자와 주요 실행 버튼은 감열 인쇄 같은 검정입니다.
- 정육점 빨강은 매장 로고, 선택된 메뉴, 작업이 막힌 상태에만 씁니다. 실행 버튼은 빨강이 아니라 검정이라서, 빨강을 보면 '멈춤'이라는 뜻으로만 읽힙니다.

이력번호와 날짜는 실제 라벨의 인쇄 칸처럼 검은 테두리 상자에 고정폭 숫자로 표시합니다. 확인, 주의, 차단 같은 상태는 색만으로 구분하지 않고 항상 아이콘과 한국어 단어를 함께 붙여 보여 줍니다.

> 화면 이미지 속 실제 이력번호와 파일 위치 정보는 가렸습니다.
